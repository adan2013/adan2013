# Hi, I'm Daniel.

I'm a Senior Software Developer specialising in React and TypeScript. I've been programming since 2013 and working professionally since 2019. I build web applications, mobile apps and backends, from architecture to deployment. As a Tech Lead, I've set technical direction and made architectural decisions while continuing to write code.

I've contributed to three commercial AI projects. My work has included LLM applications, a web-browsing agent and MCP servers that let external AI tools read and modify application data. I also use AI agents throughout development.

Outside work, I build tools for my own use, home automation and electronic devices. I write the software, solder the electronics and design enclosures for 3D printing. I document these projects on my portfolio and Redark blog.

## Selected personal projects

### Gauge Generator 2.0

I rebuilt my 2019 C#/WPF tool as a browser-based React graphics editor with layers, nonlinear scales and SVG/PDF/PNG export. I used AI during development and handled the specification, architecture and code review. Unit tests cover calculations and edge cases. The app needs no account and stores projects locally.

[Try the app](https://gauge-generator.adanit.pl/app) · [Repository](https://github.com/adan2013/Gauge-Generator)

### Smart home system

I've developed and maintained this system for my household since 2023. A React dashboard communicates with a Node.js/TypeScript backend that handles over 300 Home Assistant entities via WebSocket. I built the automations, notifications and device monitoring, with Jest tests for backend logic. We use it daily from a tablet, phones and physical remotes.

[Frontend](https://github.com/adan2013/HA-Dashboard) · [Backend](https://github.com/adan2013/HA-Backend)

### PiGuard GSM

I built a Raspberry Pi alarm for an apartment without internet. The TypeScript/Node.js application reads motion sensors and sends SMS alerts through a Huawei modem. I implemented queued AT commands, timeouts and reconnection, soldered the electronics and designed the enclosure. The device remains in use and restarts automatically after power returns.

[Repository](https://github.com/adan2013/PiGuard)

### DIY Arduino Dashboard

I built a physical instrument cluster for ETS2 and ATS, including the electronics, a C#/WPF telemetry application and Arduino firmware in C++. I kept data processing on the PC and optimised LCD rendering to update only changed regions. Diagnostic modes let me test needles, lights and the display independently of the game.

[Repository](https://github.com/adan2013/DIY-Arduino-Dashboard) · [Build log](https://redark.pl/diy-arduino-dashboard-ets-ats-eng)

### Redark

I started this technology blog in 2018 with a custom WordPress theme. In 2020, I migrated around 80 articles to Gatsby and MDX, preserving their URLs. I wrote Node.js tools for migration, link checking and deployment. The blog still runs on Gatsby; the later Next.js version remains a prototype.

[Blog](https://redark.pl) · [Gatsby repository](https://github.com/adan2013/Redark-Gatsby-Blog) · [Next.js prototype](https://github.com/adan2013/redark-next)
